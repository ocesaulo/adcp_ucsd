Step 2 — Cruise Track & Station Positions
Track waypoints draw the cruise line on the map. Stations are individually labeled markers.
Enter track waypoints in order. Latitude: negative = South. Longitude: negative = West.
Minimum 2 waypoints to draw a line. Example: Lat -57.2, Lon -64.1 → 57.2°S, 64.1°W
You can get coordinates from Google Maps (right-click → copy coordinates) or from your CODAS nav files.

Step 5 — Hosting Options

      


      Option A — GitHub Pages (recommended, free, permanent URL)
      
    
        
  1. Create a free account at github.com.
    2. 
        
  2. Create a new repository, e.g. adcp-data-portal. Make it public.
    3. 
        
  3. Upload index.html, admin.html, site_data.json, and your images/ folder.
    4. 
        
  4. Go to Settings → Pages → Source: "Deploy from branch: main / (root)".
    5. 
        
  5. Your site is live at https://yourusername.github.io/adcp-data-portal/ within ~2 minutes.
    6. 
        
  6. To update data: Edit site_data.json on GitHub (click the file → pencil icon → commit). Changes go live automatically.
    7. 
      


      
Option B — Netlify Drop (instant, drag-and-drop, free)
      
    
        
  1. Go to netlify.com/drop.
    2. 
        
  2. Drag and drop the folder containing all your files (index.html, admin.html, site_data.json, images/).
    3. 
        
  3. Get a random URL like https://happy-tesla-123.netlify.app immediately.
    4. 
        
  4. Create a free account to keep the site and set a custom subdomain.
    5. 
        
  5. To update: Re-drag the folder, or connect to a GitHub repo for automatic deploys.
    6. 
      


      
Option C — Local development (Python, no internet needed)
      
    
        
  1. Place all files in one folder.
    2. 
        
  2. Open a terminal in that folder and run:
          python3 -m http.server 8000
        
    3. 
        
  3. Open http://localhost:8000 in your browser.
    4. 
        
  4. Important: You must use python3 -m http.server (not open the HTML file directly) for site_data.json to load and for the maps to work. The fetch() API is blocked on file:// URLs.
    5. 
      


      
Adding new images
      
    
        
  1. Place image files (.jpg, .png) in the images/ folder.
    2. 
        
  2. Use this admin page to add the cruise entry, generate JSON, and paste it into site_data.json.
    3. 
        
  3. If using GitHub Pages, upload both the image files and the updated site_data.json.
    4.
