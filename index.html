About This Portal

This site presents processed ADCP data from cruises led by the Chereskin Lab. Data are available for public download from NCEI (NOAA) and from JASADCP at the University of Hawaii. Graphical images (.jpg, .pdf) may be used in publications with the credit line: "From the Chereskin Lab ADCP Data Portal, Scripps Institution of Oceanography."

For data format documentation, calibration history, and processing software, see the About page.

About This Portal
Data collection, processing methodology, and citation information.

Instrumentation

Shipboard ADCP data were collected with RD Instruments narrowband (NB, 150 kHz) and broadband (BB, 150 kHz) instruments. The transducer was mounted in the ship's hull, pinging continuously during transit and on-station periods. Data were recorded at 2-minute ensemble intervals with 8 m depth bins.

Navigation data were integrated from shipboard GPS and from the PHINS/Octans gyrocompass systems depending on cruise year. Heading corrections were applied using the Firing et al. (1995) calibration procedure based on GPS velocity.

Data Processing — CODAS3

All data were processed using CODAS3 (Common Ocean Data Access System version 3), developed by E. Firing at the University of Hawaii. Standard processing steps:

1. Navigation smoothing and heading calibration via GPS ship velocity. 2. Water-tracking mode; bottom-tracking correction when available. 3. Outlier editing and ensemble averaging. 4. Absolute velocity referencing via GPS. 5. Echo intensity profiling for bin quality assessment.

Calibration constants (amplitude A and phase φ) were determined from dedicated calibration runs and applied to correct for transducer misalignment.

Available File Formats

CODAS3 binary — native format, readable with the pycurrents Python package (UH Currents Group). NetCDF (.nc) — CF-convention compliant, one file per cruise. ASCII/CSV — tabular text of ensemble-averaged profiles. MATLAB (.mat) — available on request.

Python reading example: from pycurrents.data.navcalc import lonlat_inside_km — see the UH CODAS documentation for full API details.
